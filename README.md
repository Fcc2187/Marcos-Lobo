## 📝 Sobre o Projeto

Este projeto é um portfólio e blog dinâmico desenvolvido exclusivamente para o analista de futebol **Marcos Lobo**. O principal objetivo da plataforma é ser o cartão de visitas profissional do analista, permitindo a publicação de artigos profundos, estatísticas detalhadas e análises de desempenho de seleções e clubes.

O design foi cuidadosamente elaborado com inspiração na identidade visual do projeto **Improváveis do Cartola**, oferecendo uma experiência de usuário imersiva, limpa e moderna.

## ✨ Funcionalidades

- **🏠 Homepage Dinâmica:** Apresentação de impacto com uma seção "hero", mini-bio do analista e carrossel/prévia dos últimos artigos.
- **🏆 Cobertura Completa:** Áreas dedicadas a competições específicas (ex: Copa do Mundo 2026, Brasileirão).
- **✍️ Blog e Análises:** Roteamento dinâmico avançado gerando páginas únicas e rápidas para cada artigo utilizando dados estruturados.
- **📱 Design Responsivo:** Experiência mobile-first, com interface perfeitamente adaptável do celular ao desktop, incluindo menu hambúrguer interativo.
- **🎨 UI/UX Moderna:** Estilização componentizada com suporte a animações suaves e tipografia otimizada.
- **🚀 Alta Performance:** Otimização de imagens e carregamento rápido garantido pela arquitetura do Next.js.

## 🚀 Tecnologias e Ferramentas

O projeto utiliza o ecossistema mais moderno do React para garantir performance e escalabilidade:

- **[Next.js](https://nextjs.org/):** Framework React para renderização híbrida, rotas eficientes e otimização de SEO.
- **[React.js 19](https://react.dev/):** Biblioteca principal na sua versão mais recente para construção de interfaces de usuário.
- **[Styled-Components](https://styled-components.com/):** Estilização CSS-in-JS, garantindo escopo local e facilidade de manutenção.
- **[React Icons](https://react-icons.github.io/react-icons/):** Biblioteca completa de ícones para enriquecer a interface.
- **[Vercel Analytics]:** Monitoramento de métricas de acesso e performance em tempo real.

## 🛠️ Como rodar o projeto localmente

Siga os passos abaixo para testar o projeto no seu ambiente:

1. Clone o repositório:
   ```bash
   git clone https://github.com/Fcc2187/Marcos-Lobo.git
   ```
2. Entre no diretório do projeto:
   ```bash
   cd Marcos-Lobo/portfolio-marcos
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Acesse no seu navegador: `http://localhost:3000`

## 📦 Deploy

O deploy da aplicação é hospedado na [Vercel](https://vercel.com) e possui integração de **Deploy Contínuo (CI/CD)**. Qualquer push feito na branch `main` do GitHub dispara automaticamente o processo de build, atualizando a versão em produção instantaneamente.

🔗 **Acesse a versão ao vivo:** [https://marcos-lobo.vercel.app/](https://marcos-lobo.vercel.app/)
